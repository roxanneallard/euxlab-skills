# Glossary

Domain terms for this engagement. `/euxlab-grill-the-ask` and
`/euxlab-create-personas-and-job-stories` append here as they run.

A term earns an entry when it is fuzzy, contested, or overloaded. A word doing
three jobs is as fatal in a tax portal as it is in a codebase.

## Format

### <Term>

- **Means:** <the definition this engagement uses>
- **Used by:** <which roles use it, and whether they agree>
- **Not to be confused with:** <the neighbouring term it gets swapped with>
- **Source:** <participant ID + line range, or stakeholder name + date>
- **Status:** `agreed` | `contested` | `overloaded`

An `overloaded` entry lists every job the word is doing, numbered. Resolving it
is a decision, and decisions get a DRR.
